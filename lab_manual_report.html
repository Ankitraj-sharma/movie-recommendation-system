# 4. RECOMMENDATION LOGIC & CRITERIA

Three distinct recommendation strategies were implemented in Pandas:

  1. Criterion 1 (Global Highest Rating): Orders all records descending by Rating, utilizing Votes as a secondary sort key to break ties fairly.
  2. Criterion 2 (User Preference / Genre Filtering): Applies boolean indexing (df['Genre'] == user_genre) to filter items matching user preference, then sorts candidate matches by rating.
  3. Criterion 3 (IMDb Weighted Rating Score): Accounts for vote volume using the formula:
    Weighted Score = [v / (v + m)] × R + [m / (v + m)] × C
    where v = votes, m = 25th percentile threshold (695,000), R = movie rating, and C = dataset mean rating (8.61).

def recommend_top_by_rating(df, top_n=5): """Sorts DataFrame by Rating descending, Votes as tie-breaker.""" recommended = df.sort_values(by=["Rating", "Votes"], ascending=[False, False]).head(top_n) display_df = recommended[["Title", "Genre", "Rating", "Votes", "Release_Year"]].reset_index(drop=True) display_df.index = display_df.index + 1 return display_df

Step 4: Criterion 3 — IMDb Weighted Rating Score Function

def recommend_by_weighted_score(df, top_n=5): """Calculates Bayesian weighted score balancing rating & popularity.""" C = df["Rating"].mean() m = df["Votes"].quantile(0.25) df_scored = df.copy() df_scored["Weighted_Score"] = ( (df_scored["Votes"] / (df_scored["Votes"] + m)) * df_scored["Rating"] + (m / (df_scored["Votes"] + m)) * C ).round(2) recommended = df_scored.sort_values(by="Weighted_Score", ascending=False).head(top_n) display_df = recommended[["Title", "Genre", "Rating", "Votes", "Weighted_Score"]].reset_index(drop=True) display_df.index = display_df.index + 1 return display_df
