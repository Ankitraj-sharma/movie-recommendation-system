Self-Learning Task 3: Official Project Report

Structured report prepared for Practical 11 submission

1. Problem Selected

Selected Domain: Movie Recommendation System.
Streaming services like Netflix or Prime Video feature thousands of choices. This recommendation system uses Python and Pandas to analyze ratings, vote popularity, and user genre preferences to present the Top 3 or Top 5 recommendations.

2. Dataset Description

A structured dataset (movies_dataset.csv) containing 15 items and 6 attributes:

  • Movie_ID: Unique integer index (1 to 15)
  • Title: Name of the film
  • Genre: Primary category (Sci-Fi, Action, Drama, Animation, Romance)
  • Rating: Average score (1.0 to 10.0 scale)
  • Votes: Total number of user reviews (popularity metric)
  • Release_Year: The year of theatrical release

3. Recommendation Logic

Criterion 1 (Highest Rating): Sorts DataFrame by Rating (descending) with Votes as secondary tie-breaker.
Criterion 2 (Genre Filtering): Filters rows by user's chosen genre using boolean indexing, then selects top-rated items.
Criterion 3 (Weighted Score): Uses the IMDb formula (v/(v+m))*R + (m/(v+m))*C to eliminate low-vote bias.
